# expert-productizer

Скилл для Claude.

Продюсер эксперта: собирает из консультанта, фаундера или специалиста продаваемый продукт — позиционирование, точку зрения, формат (консультации, ретейнер, менторство, курс) и цены с обоснованием. На выходе один связный документ и первый шаг на две недели.

## Когда использовать

- Упаковать экспертизу в продукт
- Понять, сколько брать за консультации
- Перейти от найма к продаже своей экспертизы напрямую

Не подходит для юридических и налоговых вопросов, написания контента.

## Установка

**Claude Code.** Склонируйте репозиторий в папку скиллов:

```bash
git clone https://github.com/DingzhiboMike/expert-productizer.git ~/.claude/skills/expert-productizer
```

**Claude.ai / десктоп-приложение.** Скачайте репозиторий как ZIP (Code → Download ZIP) и загрузите его в настройках Claude, в разделе со скиллами.

После установки скилл включается сам, когда запрос подходит под его описание. Можно вызвать и явно — по имени `expert-productizer`.
